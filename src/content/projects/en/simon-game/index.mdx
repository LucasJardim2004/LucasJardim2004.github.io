## What it does

Simon Game is an interactive memory game. It generates a growing sequence of
tones and colours that the player must repeat in order. Each round adds one new
step, increasing the difficulty.

## Key features

- Dynamic sequence generation
- Sound and visual feedback on every button
- Score tracking, highest streak, and a restart flow

## Tech stack

HTML5, JavaScript, CSS3, and Bootstrap 5.

## My role & challenges

I designed and built the full game loop and UX. The main challenge was balancing
the timing between the audio-visual cues and user input to keep it responsive and
fun.

## What I learned

- Event handling and debouncing user input
- Managing state and scaling difficulty
- Organising JavaScript into small, testable functions
