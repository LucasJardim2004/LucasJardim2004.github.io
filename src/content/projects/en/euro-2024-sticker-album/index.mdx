## What it does

Euro 2024 Sticker Album is a full-stack web app that recreates the fun of
collecting football stickers, built for the Web Development and Mobile
Applications course. It includes user authentication, a homepage, a forum for
discussions, a store to buy random sticker packs, a personal album that displays
your collection, and a profile page.

## Key features

- Secure authentication and session handling
- A forum for users to communicate and trade ideas
- A store with a random pack-opening animation and inventory updates
- An album grid that shows owned and missing stickers
- A user profile with basic settings and collection stats

## Tech stack

Django and Python on the back end, React on the front end, Bootstrap 5 for UI,
and SQLite for storage.

## My role & challenges

This was a pair project and I worked across the stack: Django views, URLs, and
models for auth, shop, and album logic; React components for pack creation, the
album grid, and forum threads; and the Bootstrap UI polish. The key challenges
were keeping React state in sync with Django sessions, validating purchases and
inventory updates automatically, and designing a schema that keeps pack opening
fair and reproducible.

## What I learned

- Django auth flows, forms, and messages
- Connecting React components to Django endpoints
- Reusable UI with Bootstrap 5 and component composition
- Inspecting and debugging with DB Browser for SQLite
