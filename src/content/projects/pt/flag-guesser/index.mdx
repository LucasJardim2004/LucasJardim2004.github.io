## What it does

Flag Guesser displays a flag and asks the player to type the country's name. The
input is validated against a PostgreSQL database — with case and accent
normalisation — and if it matches, it counts as correct and the game moves on to
the next flag.

## Key features

- Random flag selection from the database
- Server-side validation with normalised, accent- and case-insensitive matching
- Immediate correct/wrong feedback and score tracking

## Tech stack

Node.js, Express, PostgreSQL, EJS, and JavaScript.

## My role & challenges

I implemented the whole flow end to end: the UI, the API, and the data layer.
The biggest challenge was normalising user input — accents, spacing, name
variations — and ensuring efficient database matching with `ILIKE` and
normalisation functions without hurting performance.

## What I learned

- Designing a small validation API in Express
- Parameterised queries in PostgreSQL
- String normalisation — case folding and accent removal — and `ILIKE`
- Basic indexing and performance considerations in text matching
